# Notes

Android-застосунок «Нотатки» з синхронізацією з хмарним сховищем (Firebase Firestore).
Лабораторна робота 3.

## Можливості

- Створення, редагування й видалення нотаток
- Локальне збереження (Room), застосунок працює без інтернету
- Ручна синхронізація з хмарою, конфлікти вирішуються за принципом «остання зміна перемагає»
- Інтерфейс українською та англійською мовами, перемикання мови в застосунку
- Логування через SLF4J + logback-android

## Технології

Java, Android SDK, Room, Firebase Firestore, ViewModel + LiveData,
JUnit 4, Mockito.

## Структура проєкту

| Пакет | Призначення |
|---|---|
| `model` | модель даних `Note` |
| `data.local` | база даних Room (entity, DAO, мапер) |
| `data.remote` | інтерфейс хмари та його реалізація для Firestore |
| `data.sync` | правила розв'язання конфліктів синхронізації |
| `data.repository` | репозиторій, що об'єднає локальні й хмарні дані |
| `ui` | екран, адаптер списку, ViewModel |
| `i18n` | вибір мови застосунку |

## Запуск

1. Створіть проєкт у [Firebase Console](https://console.firebase.google.com),
   додайте Android-застосунок з пакетом `com.lab.notes`.
2. Увімкніть Firestore Database (режим test mode).
3. Завантажте `google-services.json` і покладіть його в папку `app/`.
   Файл не зберігається в репозиторії (див. `.gitignore`).
4. Відкрийте проєкт в Android Studio та запустіть конфігурацію `app`.
