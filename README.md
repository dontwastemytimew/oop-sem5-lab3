# Notes

Android-застосунок «Нотатки» з синхронізацією з хмарним сховищем (Firebase Firestore).
Лабораторна робота 3.

## Можливості

- Створення, редагування й видалення нотаток
- Локальне збереження (Room): застосунок працює без інтернету
- Ручна синхронізація з хмарою; конфлікти вирішуються за принципом
  «остання зміна перемагає»
- Інтерфейс українською та англійською мовами, перемикання мови в застосунку
- Логування через SLF4J + logback-android
- Юніт-тести (JUnit 4, Mockito)

## Технології

Java, Android SDK (minSdk 24), Room, Firebase Firestore, ViewModel + LiveData,
RecyclerView, SLF4J + logback-android, JUnit 4, Mockito.

## Як користуватися

- Кнопка **+** відкриває форму нової нотатки.
- Дотик до нотатки відкриває її для редагування.
- Довге натискання на нотатку пропонує видалити її.
- Кнопка синхронізації на верхній панелі обмінюється даними з хмарою.
- Меню з трьома крапками -> **Мова / Language** перемикає мову інтерфейсу.

## Архітектура

Застосунок поділений на шари. Кожен шар знає лише про той, що нижче, і
спілкується з ним через інтерфейси:

```
Екран (MainActivity, NotesAdapter)
        |
   NotesViewModel (LiveData)
        |
   NoteRepository  (інтерфейс)
        |
   NoteRepositoryImpl
     |          |             \
  NoteDao   NoteRemoteDataSource   NoteConflictResolver
  (Room)    (Firestore)            (LastWriteWins)
```

- **ViewModel** зберігає дані екрана й переживає його перестворення
  (наприклад, поворот телефона).
- **LiveData** повідомляє екран про зміни даних, тому список оновлюється сам.
- Усі звернення до бази й хмари виконуються у фоновому потоці.

## Структура пакетів

| Пакет | Призначення |
|---|---|
| `model` | незмінна модель даних `Note` |
| `data.local` | база даних Room: `NoteEntity`, `NoteDao`, `AppDatabase`, `NoteMapper` |
| `data.remote` | інтерфейс хмари `NoteRemoteDataSource`, реалізація для Firestore, `RemoteSyncException` |
| `data.sync` | правила розв'язання конфліктів: `NoteConflictResolver`, `LastWriteWinsResolver` |
| `data.repository` | `NoteRepository` та його реалізація, що об'єднує локальні й хмарні дані |
| `ui` | екран, адаптер списку, `NotesViewModel` та її фабрика, `SyncState` |
| `i18n` | вибір мови застосунку: `AppLanguage`, `LanguageManager` |

## Як працює синхронізація

Нотатки спершу зберігаються локально, а з хмарою обмінюються за командою
користувача. Для кожної нотатки (за її `id`) діє правило:

| Ситуація | Що робить застосунок |
|---|---|
| Є лише на телефоні | завантажує в хмару |
| Є лише в хмарі | зберігає на телефоні |
| Є в обох місцях, версії різні | лишає новішу (за часом зміни) і оновлює старішу копію |
| Є в обох місцях, версії однакові | нічого не змінює |

Якщо хмара недоступна, користувач бачить повідомлення про помилку, а
локальні дані не втрачаються.

## Логування

Використовується SLF4J з реалізацією logback-android. Налаштування лежить у
`app/src/main/assets/logback.xml`. Повідомлення виводяться в Logcat; помилки
записуються разом зі стеком винятку.

## Багатомовність (i18n)

Усі тексти зберігаються в `strings.xml`: англійські в `res/values`,
українські в `res/values-uk`. Мову можна змінити в самому застосунку (меню -> «Мова»), вибір зберігається між запусками. Підтримувані мови описані в
`res/xml/locales_config.xml`.

## Запуск

1. Створіть проєкт у [Firebase Console](https://console.firebase.google.com),
   додайте Android-застосунок з пакетом `com.lab.notes`.
2. Увімкніть Firestore Database (режим test mode).
3. Завантажте `google-services.json` і покладіть його в папку `app/`.
   Файл не зберігається в репозиторії (див. `.gitignore`).
4. Відкрийте проєкт в Android Studio та запустіть конфігурацію `app`.
